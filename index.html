Web Components y LitElement

Este portafolio está hecho con componentes Lit propios: <project-card>, <site-preview>, <growth-meter>, <intent-picker>… con Shadow DOM, propiedades reactivas, slots, eventos personalizados y temas por custom properties. Es la misma base (Lit + estándares web) sobre la que se construyen frameworks empresariales de componentes como CELLS. 

export class ProjectCard extends LitElement {
  static properties = {
    name: { type: String },
    url: { type: String },
    previewable: { type: Boolean },
  };

  _openPreview() {
    this.dispatchEvent(new CustomEvent('preview-open', {
      detail: { url: this.url, name: this.name },
      bubbles: true, composed: true,
    }));
  }
}
customElements.define('project-card', ProjectCard);
